ВАЖНО: не заменяйте весь index.ts этим архивом.
В Supabase сейчас развернута версия v3-english, которой нет в исходном ZIP.

В текущем index.ts найдите:

const expectedSecret = Deno.env.get('NOTIFY_WEBHOOK_SECRET') ?? ''

и замените только на:

const expectedSecret = Deno.env.get('NASTYA_ROZA_NOTIFY_WEBHOOK_SECRET') ?? ''

После этого в Supabase Secrets создайте:
NASTYA_ROZA_NOTIFY_WEBHOOK_SECRET = <ваш случайный код>

И в GitHub Repository Secrets создайте секрет с тем же именем и тем же значением:
NASTYA_ROZA_NOTIFY_WEBHOOK_SECRET = <тот же случайный код>
