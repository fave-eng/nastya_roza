Grammar note 2

Present Simple vs Present Continuous

Привычка и факт vs действие сейчас.

Present SimplePresent Continuous
Когда?привычки, факты, регулярные действиядействие сейчас / временная ситуация
УтверждениеI work. / She works.I am working. / She is working.
ОтрицаниеI don’t work. / She doesn’t work.I’m not working. / She isn’t working.
ВопросDo you work? / Does she work?Are you working? / Is she working?
Подсказкиusually, often, every daynow, at the moment, this week

I work Monday to Friday. → обычная ситуация.

I’m working now. → действие происходит сейчас.

3rd person: work → works, watch → watches, study → studies. -ing: live → living, run → running.

Grammar note 3

I’ll for offers

Короткая формула для предложения помощи.

MeaningFormExample
предлагаем помощь / решаем что-то сделать сейчасI’ll + base verbI’ll help you. / I’ll send somebody up.

После will глагол остаётся в начальной форме: I’ll ask ✓, I’ll asks ✗.

Grammar note 6

Past Continuous

Действие было в процессе в определённый момент в прошлом.

FormPatternExample
Positivesubject + was / were + verb-ingThey were playing.
Negativewasn’t / weren’t + verb-ingIt wasn’t raining.
QuestionWas / Were + subject + verb-ing?Were you working?
Short answerYes, ... was/were. / No, ... wasn’t/weren’t.Yes, I was.

Past Continuous + Past Simple

Long action in progress → Past Continuous

Short event → Past Simple

Mark was talking on the phone when he got a text.

I was writing a report when my computer crashed.

-ing: work → working · write → writing · get → getting.

Grammar note 7

Time sequencers and connectors

Порядок событий, причина, результат и контраст.

ФункцияСловаПример
SequenceOne summer · The next day · Two minutes later · After that · SuddenlyAfter that, we travelled together.
ReasonbecauseI went home because I was tired.
ResultsoI was tired, so I went home.
Contrastbut · althoughAlthough it was expensive, I bought it.
Time linkwhenI was tired when I reached the top.

because gives the reason; so gives the result.

but joins two contrasting ideas; although introduces the “although ...” clause.

Avoid: Because ..., so ... ✗ and Although ..., but ... ✗ for the same logical link.
