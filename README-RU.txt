АНАСТАСИЯ + РОЗАЛИНА · ENGLISH SPACE A1
========================================

Что изменено
------------
1. На одном сайте есть два профиля:
   - Анастасия (student_id: anastasia)
   - Розалина (student_id: rozalina)

2. На каждой основной странице сверху есть переключатель ученицы.
   Выбранный профиль сохраняется и передаётся в ссылках через ?student=...

3. Прогресс полностью раздельный для:
   - домашних работ;
   - грамматики;
   - словаря.

4. Выполнение задания одной ученицей НЕ отмечает его выполненным у второй.

5. Уровень курса: A1.
   В комплект добавлены 4 стартовых A1-урока, 4 темы грамматики и 4 темы словаря.
   Их можно заменить своими материалами, сохранив структуру файлов.

Основные файлы
--------------
config.js                    — ученицы, уровень, Supabase
app.js                       — логика сайта и раздельного прогресса
data/lessons/lesson-N.json   — домашние работы
data/grammar-data.js         — грамматика
data/vocabulary-data.js      — словарь
supabase/two-students-setup.sql — настройка базы для двух профилей
supabase/functions/notify-telegram/index.ts — Telegram-отчёты

Как работает переключение
--------------------------
Например:
  homework.html?student=anastasia
  homework.html?student=rozalina

При переключении сайт перезагружает текущую страницу с выбранным student_id.
LocalStorage и Supabase используют student_id в ключах/строках, поэтому данные
двух учениц не смешиваются.

Supabase
--------
Перед использованием облачной синхронизации один раз выполните:
  supabase/two-students-setup.sql

в Supabase Dashboard -> SQL Editor.

Скрипт создаёт/обновляет таблицы прогресса, разрешает student_id anastasia и
rozalina и исправляет Telegram-схему так, чтобы один chat_id можно было
использовать для двух учениц.

Telegram
--------
В отчёт о сданной домашней работе теперь добавляется имя ученицы.
Один и тот же Telegram-чат преподавателя можно привязать к обеим ученицам.

Если chat_id преподавателя отличается от значения в SQL-файле, замените его
в двух строках INSERT в конце supabase/two-students-setup.sql.

Важно
-----
Supabase URL и anon key оставлены из исходного проекта. Если новый сайт будет
использовать другой Supabase-проект, замените их в config.js и разверните
Edge Function notify-telegram в новом проекте.
